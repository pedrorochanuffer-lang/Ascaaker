# Ascaaker

Gere desenhos em ASCII com IA usando [WebLLM](https://mlc.ai/web-llm/) via navegador. Pronto para deploy no GitHub Pages.

## Use
1. Abra `https://SEU_USUARIO.github.io/SEU_REPO/` após o deploy.
2. Digite sua descrição no campo e clique em "Gerar ASCII Art".
3. Veja e copie sua arte!

## Rodando localmente
```sh
npx serve public
```

---

## 🚀 Deploy
O GitHub Actions já está configurado. Só commite e dê push na main. Acesse pelo link do Pages do seu repo!
